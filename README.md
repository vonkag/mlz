# meal-list

Weekly grocery lists generated from a 28 day meal plan, published as plain pages
carrying schema.org/Recipe structured data so the [Bring!](https://www.getbring.com)
shopping app can import them in one tap.

Quantities cover two adults and a toddler. Pages are `noindex`.

Regenerated by `build-bring-pages.mjs` from the plan data; do not hand-edit.
